# Work tracking

## What it does

The Work tracking module makes sure that every open repair, installation project and supplier escalation has a next action and a person who owns it. Jobs that wait for parts or for a customer's approval show what they are waiting for, so nothing sits silently for weeks. When a job is solved, the module turns the notes into a fix note that a senior technician reviews, so knowledge stops living only in a few people's heads.

## What is included

- A next action and an owner per job, visible to the whole team.
- Parts and approval waiting states that say exactly what a job depends on.
- An installation readiness checklist completed before anyone travels to install.
- Supplier escalation history, keeping every contact with a manufacturer or distributor about a stuck case.
- Reviewed fix notes written from solved jobs and checked by an experienced technician.

## What it does not do

The work-tracking module does not order parts; it shows that a job is waiting for them. The work-tracking module does not diagnose faults, which stays the technician's job. The work-tracking module does not close a job without a person, so every closure has a name next to it.

## Connecting it to your tools

- Spreadsheet import: a job list kept in spreadsheets can be loaded into work tracking and exported again as CSV files, with no live connection. No surcharge is added.
- Email capture: work tracking can attach supplier replies from a shared mailbox, read with the business's permission, once a one-working-day setup is done. It adds 150 USD a month.
- Service software API: work tracking can follow open jobs in a service management application that offers an API with an access key, with two working days of setup. Work tracking adds 300 USD a month for the API link.

When work tracking is chosen next to other modules, every shared integration is still charged only once, so a mailbox or API used by several modules costs its surcharge a single time.

## Price

The base monthly price for work-tracking is 360 USD. Starting work tracking involves a one-time setup fee of 1200 USD. The work tracking base price is multiplied by the technician factor of 1.00 for up to 5 field technicians, 1.30 for up to 15 or 1.60 for up to 30.
