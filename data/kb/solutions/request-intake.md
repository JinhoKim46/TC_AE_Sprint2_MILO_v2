# Request intake

## What it does

The Request intake module gathers every service request into one shared queue, whether it arrived as a phone note, an email or a chat message. When a new request comes in, it shows the open incidents that look related, so the coordinator can spot a second report about the same device before a second technician is sent. Each request records who accepted it and what was promised, which closes the gap where everybody assumes somebody else took the call.

## What is included

- One shared request queue that the office, the coordinator and the technicians all read from.
- Capture from email and chat, so messages sent to a person's inbox or phone become queue entries instead of private reminders.
- Related-incident hints that place a new report next to open incidents for the same site or device.
- An acceptance owner per request, naming the person who took responsibility for it.
- A commitment log that keeps every promise made to a customer, with its time and the person who made it.

## What it does not do

The request-intake module does not merge requests without a coordinator decision; it only suggests that two reports may belong together. The request-intake module does not replace the customer's phone system, and callers keep phoning the numbers they already use. The request-intake module does not force a mandatory customer portal on anyone, because customers who prefer to call or write must still be served.

## Connecting it to your tools

- Spreadsheet import: for request intake, an existing request list kept in spreadsheets is brought in and sent back out as CSV files, without any live connection. This integration carries no monthly surcharge.
- Email capture: request intake reads a shared mailbox with the business's permission, and connecting that mailbox takes one working day. It adds 150 USD a month.
- Service software API: if the business's service management application offers an API with an access key, request intake can use it after two working days of setup. The API connection adds 300 USD a month to request intake.

## Price

The base monthly price for request-intake is 420 USD. Setting up request intake costs a one-time fee of 1200 USD. That 420 USD figure is multiplied by the technician factor for the number of field technicians: 1.00 for up to 5, 1.30 for up to 15 and 1.60 for up to 30. The estimate tool works this out from the recorded facts.
